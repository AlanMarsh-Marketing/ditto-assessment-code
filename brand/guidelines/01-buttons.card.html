Don't decorate buttons with icons. The label carries the action on its own — no leading arrow, sparkle or subject icon for visual interest. Add an icon only when it is functional or utility: a dropdown / split button (ui-chevron-down), a back action (ui-back), a dismiss, or a media control such as play / pause. Then use a ui-* utility icon at 16px, one per button, on the side that matches its meaning — and match the icon colour to the button's text colour (purple on outline, orange on ghost, white on primary / secondary; set --icon-ink:currentColor). Never a second colour inside a button.
Never add glows or drop shadows to buttons — in UI or creative assets. Use them exactly as shown.
